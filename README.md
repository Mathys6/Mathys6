A governance layer for Claude Code distilled from that production practice: a contract of hard rules re-injected at every session, a drift log, an anti-complacency command, verification skills and the design of a CI gate for agent-written code.

Nothing is sent without my validation. Python tooling, one Claude Code agent per step, MCP, a local runner.
